Using this example on another website

Add that website's hostname to the frontend key's allowed domains in Integrations → API Keys. This GitHub preview uses sgumerrabbani.github.io. Then reload the page.

The downloaded HTML includes the library in its head and both widget snippets. Upload it to an allowed website and open it over HTTPS; opening it directly from your Downloads folder does not give it an allowed website origin.

This example uses the supplied widget ID. For Augusta or another masjid, replace both widget snippets with code copied from that masjid's own portal. A frontend msj_pk_ key is intended for website embeds; never insert an msj_sk_ server key.
