Display a QR code so visitors can open an event page, donation page, registration form, or another link on their phone. You can show it as a slideshow image or place it beside prayer times on a compatible timing screen.

Professional plan

The options in this guide assume your masjid has the Professional (Pro) plan. Have your QR code saved as an image before starting, and scan it with your phone to check the destination.

Choose where to display your QR code

Option 1: Display the QR code as an image

  1. Sign in to your Masjidal portal.
  2. Open Slideshow → New Content.
  3. Select Image. This is the display-image option.
  4. Give the content a name and upload your QR-code image. You can also upload a poster that includes the QR code and instructions explaining what it opens.
  5. Set the schedule for when the image should appear. Select a zone if it should appear only on particular screens. If you want the image beside prayer times, use the Split Screen option.
  6. Click Save and check the TV during the scheduled display time.

This option uses the slideshow image settings. You do not need a timing-screen layout with a dedicated QR-code area. See Displaying Images for the image controls and Slideshow for scheduling.

Option 2: Add the QR code to the timing screen

A compatible timing screen is required.

Uploading the QR image alone will not add a QR-code area to every theme. Select a supported timing screen under Settings → Al-Iqamah as part of this setup.

1. Upload your QR code

  1. Open Slideshow → New Content.
  2. Select QR Code. Its description refers to displaying a QR code on the timing screen.
  3. Upload your QR-code image in the Display QR Code editor. Use a square image; the illustrated editor specifies 400 × 400 px or 500 × 500 px.
  4. Make sure the content status is Active and click Save.

2. Select a timing screen that supports QR codes

  1. Open Settings → Al-Iqamah.
  2. Use Change Screen to open the timing-screen choices.
  3. Choose a layout whose preview includes a QR code. Some layouts have a dedicated QR area; others do not.
  4. Click Select, then Save on the settings page.
  5. Check the TV to confirm that the QR code appears beside the prayer times.

For more detail about layouts and preparing a transparent image, see QR Code on Timing Screen.

Check that visitors can scan it

  • Scan the QR code from the actual TV with a phone, from the distance visitors will use it.
  • Confirm that it opens the intended page and that the page works on a phone.
  • Keep the QR pattern sharp, with good contrast and clear space around it. Avoid stretching it or placing text over the pattern.
  • For the image option, leave the image visible long enough for someone to scan it.

If the QR code does not appear

  • Using the Image option? Check the content schedule, selected zone, and whether the TV is showing the slideshow at that time.
  • Using the QR Code option? Check that the QR content is Active and saved, and that the selected timing screen includes a QR-code area.
  • Make sure the player is connected to the internet. If an option is unavailable on an older app, follow Updating Al-Iqamah.
  • If the code appears but will not scan, test the original image on your phone, then check the TV's image size, contrast, and scan distance.
